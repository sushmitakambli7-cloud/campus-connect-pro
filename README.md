# Campus Connect Pro

## Project Overview

Campus Connect Pro is a web-based Campus Management Application developed using Python and Flask. It provides a structured backend and responsive user interface for managing campus-related data.

## Features

* Student management
* Course management
* Dashboard data management
* CRUD operations
* Database relationships
* Flask Blueprints
* SQLite database integration
* Responsive user interface

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* Bootstrap
* Jinja2

## Project Description

The application uses Flask Blueprints to organize backend modules and SQLite for database integration. CRUD operations are implemented for efficient management of application data. The user interface is developed using HTML, CSS, Bootstrap, and reusable Jinja2 templates.
